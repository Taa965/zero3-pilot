# 从源码启动 Zero3

双击仓库根目录的 `Start-Zero3.cmd`，或在 CMD 中执行它。
需要已安装 Node.js，首次启动沿用项目现有的依赖准备与构建流程。

- 启动成功后 CMD 会回到前台，保留构建和运行日志。
- 修改并保存源码后，在此 CMD 按 **R**（无需回车）。脚本会关闭自己启动的实例，重新应用源码覆盖层、编译并启动。
- 按 **Q** 或 **Ctrl+C** 正常退出。不要直接关闭 CMD，以便脚本清理开发进程。
- 构建失败时窗口仍保留，修正代码后按 **R** 重试。

R 会重启 Electron，因此主进程、预加载和 `apps/zero3-desktop` 中的源模板改动都能生效；运行中的临时状态可能重置。直接修改已生成的前端文件时，Vite 仍提供自动热更新，但生成文件会在下次 R 时由源码覆盖。
每次重建前，旧的受 Git 跟踪的生成文件会备份到仓库的 `output/desktop-source-backups/`，再从固定版本重新应用覆盖层，避免重复插入代码。

R 复用已编译的 Codex 内核。修改 Rust 内核后，需要先单独完成内核构建，再按 R 加载新二进制；首次没有内核二进制时，启动流程会按项目原流程准备并构建它。

如果已有开发实例占用 5174 或 9222 端口，先关闭该实例，再按 R。脚本不会关闭其他启动来源的进程。
配置继续使用 `%USERPROFILE%\Documents\Zero3 Pilot`，启动来源不会改变配置目录。
